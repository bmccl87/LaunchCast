# LaunchCast

The model.keras file is the TensorFlow v2.15.0 based model for deployment. 

The test_data.nc file is an example set of the data used as input. It is congruent with the model prediction made in Figure 5 in the paper. 

To run the model, please look at the Jupyter Notebook for code to run the model. 

If the model.keras file does not load, it is an issue with the tensorflow environment. 

The python environment yaml file is also included for transparency.
